# NOIR — Haute Couture & Architectural Garments

A cinematic high-end fashion editorial and modern e-commerce platform built with Next.js 15, React 19, TypeScript, Tailwind CSS, Framer Motion, and GSAP ScrollTrigger.

![NOIR Atelier](https://images.unsplash.com/photo-1509631179647-0177331693ae?q=80&w=1200&auto=format&fit=crop)

## Features

- **Cinematic Architecture**: Editorial magazine layout, kinetic typography, dynamic lookbooks, and luxury monochrome aesthetic.
- **Scroll-Driven Motion**: GSAP horizontal pin and scroll-linked vertical model parallax across curated capsules.
- **Complete Atelier Shop**: Multi-filter catalog (categories, silhouettes, materials, colors, price ranges, sort options) with responsive search.
- **Multi-Gateway Payment System**:
  - **Credit & Debit Cards**: Visa, MasterCard, American Express with 1-click test fill credentials.
  - **bKash (বিকাশ)**: Direct Bangladesh MFS integration with live BDT conversion, account verification, and PIN simulation.
  - **Nagad (নগদ)**: Postal MFS financial gateway with OTP and secure PIN clearance.
  - **Apple Pay & Google Pay**: 1-Click biometric tokenized authentication (Face ID / Touch ID Enclave simulation).
  - **Cash on Delivery (COD)**: Doorstep parcel inspection and courier collection.
- **Authentication & Security Gate**: Role-based authentication (Client Patron & Admin Portal), password gate, and checkout protection.
- **Client & Admin Dashboards**: Customer order history tracking with gateway metadata, and an administrative hub with real-time order status management and revenue analytics.

## Tech Stack

- **Framework**: [Next.js 15](https://nextjs.org/) (App Router)
- **UI & Logic**: React 19, TypeScript
- **Styling**: Tailwind CSS, Vanilla CSS
- **Animations**: GSAP, ScrollTrigger, Framer Motion, Lenis Smooth Scroll
- **Icons**: Lucide React

## Getting Started

1. Clone repository:
   ```bash
   git clone https://github.com/SamiumBashir/noirEcommerce.git
   cd noirEcommerce
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Run development server:
   ```bash
   npm run dev
   ```

4. Open [http://localhost:3000](http://localhost:3000) or [http://localhost:3001](http://localhost:3001) in your browser.
